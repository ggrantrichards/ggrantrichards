# Glenn Grant-Richards

M.S. student in Natural Language Processing at UC Santa Cruz. I work on LLM safety, mechanistic interpretability, activation steering, and agent security.

[Portfolio](https://ggrantrichards.github.io/) · [Google Scholar](https://scholar.google.com/citations?user=AOa3lUAAAAAJ) · [LinkedIn](https://www.linkedin.com/in/glenn-grant-richards)

## Research

- **[Component and Dimension Sparsity in Transformer Refusal Mechanisms](https://github.com/wang-research-lab/Refusal_Mechanisms)** — second author, COLM 2026. Studying the components and dimensions that support refusal steering.
- **[Safety-Preserving Compression for Agentic Traces](https://github.com/ggrantrichards/245-project)** — evaluating how compression affects a safety critic's attack detection and benign refusal.
- **[SpeechBreak dataset audit](https://github.com/ggrantrichards/SpeechBreak/tree/glenn/dataset-audit)** — annotation tooling, dataset summaries, and review workflows in my research fork.
- **Gaze-Based Automatic Scrolling for Readers Using Screen Magnification** — first author, ETRA 2026. [Paper](https://escholarship.org/uc/item/2xc5x99g).
- **[PICA / Asking for Trouble](https://github.com/ggrantrichards/PICA)** — UCSC capstone research with Scale AI and MIT on prompt injection through agent clarification. My Machine Learning Visiting Researcher affiliation with Scale AI is through this capstone collaboration. The working repository is private; its code is available only to authorized collaborators.

My research also involves working with [RepIt](https://github.com/wang-research-lab/RepIt), [SteeringSafety](https://github.com/wang-research-lab/SteeringSafety), and [persona_vectors](https://github.com/safety-research/persona_vectors). These links point to the original projects; specific contributions and experiments are described in the linked work.
